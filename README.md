# 游戏内视频播放与过场动画系统

## 项目描述

游戏内视频播放与过场动画系统的bug修复项目。核心模块 `video/player.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 帧解码完全没做播放时只有声音没有画面
- 帧缓冲完全没做解码后帧直接显示
- 音频同步完全没做声音和画面差5秒
- 字幕渲染完全没做播放时没有字幕
- 播放控制完全没做不能暂停和快进

## 运行测试

```bash
python -m pytest tests/test_player.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
